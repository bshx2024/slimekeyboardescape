## ✨ Key Features

- **🎮 3D WebGL Action**: Immersive browser-based platformer powered by HTML5 & Three.js — zero downloads or installations required.
- **⌨️ Keyboard Trap Challenges**: Navigate across a perilous grid of giant mechanical keycaps, dodging spike traps and crushing switches.
- **⚡ Speed Boost System**: Gain `+1 speed` per step! Redeem secret in-game codes (e.g. `BYP4SS1`) for massive velocity boosts.
- **🏫 School & Work Unblocked**: Optimized for lightning-fast load times across desktop and mobile devices under restricted network environments.
- **🎨 Modern Glassmorphism UI**: High-end dark theme inspired by top modern web apps, with responsive touch and keyboard controls.

## 🚀 Quick Start & Local Development

Because this is a lightweight HTML5 static WebGL application, you can run it locally with any static web server:

```bash
# Option 1: Python 3
python -m http.server 8000

# Option 2: Node.js (npx)
npx http-server -p 8000
```

Once running, visit `http://localhost:8000` in your web browser.
